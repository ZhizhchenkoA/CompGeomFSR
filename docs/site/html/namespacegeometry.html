Функции

◆ convexHull()

std::vector< Point > geometry::convexHull ( std::vector< Point > points,
double eps = 1e-9 )

Выпуклая оболочка множества точек алгоритмом Эндрю.

Возвращает
Вершины против часовой стрелки без повторения первой точки. Для 0/1/2 различных точек результат содержит 0/1/2 точки. Дубликаты и коллинеарные внутренние точки исключаются.
Сложность: O(n log n) по времени, O(n) дополнительной памяти.
Инвариант: Результат ориентирован против часовой стрелки.

◆ delaunayTriangulation()

std::vector< DelaunayTriangle > geometry::delaunayTriangulation ( std::vector< Point > points,
double eps = 1e-9 )

Триангуляция Делоне алгоритмом Bowyer–Watson.

Дубликаты исключаются; для менее чем трёх неколлинеарных точек возвращается пустой список. Точки на окружности допускаются.

Сложность: В среднем O(n log n), в худшем случае зависит от числа треугольников.

◆ turn()

int geometry::turn ( const Point & a,
const Point & b,
const Point & p,
double eps = 1e-9 )

Предикат поворота.

Возвращает
1, если p слева от ab; -1, если справа; 0, если на прямой.
Аргументы
aНачало направленного отрезка.
bКонец направленного отрезка.
pПроверяемая точка.
epsДопуск, при котором значение считается нулём.
Сложность: O(1)
Постусловие
Возвращаемое значение всегда принадлежит множеству {-1, 0, 1}.
Заметки
Отрицательный eps обрабатывается как его абсолютное значение.
Предупреждения
Для координат, заданных очень длинными десятичными строками, используйте bigint::exactTurn: арифметика double может потерять знак.
См. также
cross(), bigint::exactTurn()
Учебная заметка: Знак векторного произведения — основа теста «слева/справа».
Примеры
turn_example.cpp.
