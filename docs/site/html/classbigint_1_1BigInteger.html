Библиотека точной арифметики для задачи с длинными координатами.

Знаковое целое произвольной длины в базе 10^9.

Инвариант: Ноль хранится только со знаком 0 и без старших нулевых блоков.
Необходимо сделать
Реализовать деление с остатком, если библиотека выйдет за рамки задачи 3.
