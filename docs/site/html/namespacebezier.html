◆ deCasteljau()

geometry::Point bezier::deCasteljau ( const std::vector< geometry::Point > & control,
double t )

Операции с параметрическими кривыми Безье.

Вычисляет точку кривой Безье в параметре t методом де Кастельжо.

\[Q_i^{(r)}=(1-t)Q_i^{(r-1)}+tQ_{i+1}^{(r-1)}.\]

Заметки
Значение t ограничивается интервалом [0, 1].
Визуализация
Промежуточные уровни построения доступны через deCasteljauLevels().
