◆ exactTurn()

bool bigint::exactTurn ( const std::array< std::string, 6 > & coordinates,
int * sign,
std::string * error )

Поля массива идут в порядке Ax, Ay, Bx, By, Px, Py.

Точно вычисляет знак (B - A) x (P - A) для строковых чисел.

Конвейер точного вычисления

\[\operatorname{sign}\big((B-A) \times (P-A)\big) \in \{-1,0,1\}.\]

Предусловие
Указатели sign и error не равны nullptr.
Постусловие
При успехе *sign имеет значение -1, 0 или 1.
Предупреждения
Экспоненты с модулем больше 100000 отклоняются, чтобы ограничить объём памяти, требуемый для выравнивания десятичных степеней.

geometry::turn()
